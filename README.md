# Aprende Blackjack

App web para aprender a jugar blackjack, en español y sin dependencias.

- **Aprende:** las reglas explicadas en 6 pasos simples.
- **Guía:** estrategia básica con reglas rápidas, tablas completas, glosario y errores típicos.
- **Practica:** mesa de juego con fichas virtuales y un entrenador que te dice si cada jugada fue la correcta y por qué.

## Cómo usarla

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
```

Reglas de la mesa: 6 barajas, blackjack paga 3:2, el crupier se planta en todos los 17, se puede doblar con cualquier par de cartas (también tras dividir) y se permite una división por mano.
